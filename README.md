# epik8s-pyioc: containerized Python IOCs driven by `values.yaml`

`epik8s-pyioc` is for Python IOCs what an ibek support YAML is for C IOCs:

1. **`pyioc.yaml`**, a support definition shipped inside the IOC image. It declares the
   IOC's parameters: types, defaults, ranges and docs.
2. **`pyioc-run`**, the single start command of every Python IOC. It reads the IOC entry
   that ioc-chart writes to `/tmp/iocconfig.yaml`, validates it against the spec, and calls
   the IOC with typed parameters.
3. **`pyioc`**, tooling derived from the spec: a project generator, checks, JSON Schema,
   docs, the `iocDefaults` block, and validation of a beamline `values.yaml`.

An IOC is then deployed from the beamline `values.yaml` alone, with no
`config/iocs/<ioc>` directory, no `start.sh`, no `template` and no ibek:

```yaml
iocDefaults:                     # generated by: pyioc defaults
  thorlabscct:
    charturl: https://github.com/infn-epics/ioc-chart.git
    devtype: thorlabscct
    devgroup: diag
    image: ghcr.io/infn-epics/thorlabscct:0.2.4
    start: pyioc-run
    pva: false
epicsConfiguration:
  iocs:
    cct01:
      devtype: thorlabscct
      iocprefix: SPARC:DIAG
      server: ddsparcthorcs001.lnf.infn.it
      devices:
        - name: CCT01
```

## Quick start

```sh
pip install "epik8s-pyioc @ https://github.com/infn-epics/epik8s-pyioc/archive/refs/tags/v0.2.1.tar.gz"
pyioc init mydev            # or: pyioc init mydev --from description.yaml
cd mydev && pip install -e '.[test]' && pytest
```

The reference IOC is [thorlabscct](https://github.com/infn-epics/thorlabscct), the Thorlabs
CCT spectrometer at SPARC.
